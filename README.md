# 坦克大战 · Battle City

一个纯 HTML/CSS/JavaScript（Canvas）实现的经典坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制我方坦克，保护底部基地，消灭所有敌军坦克即可过关。
- 共 5 关：前两关为固定地图，之后为随机生成地图，难度逐渐提升。
- 敌军会瞄准你射击，也会摧毁砖墙开辟通路逼近基地。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击 |
| P / Esc | 暂停 |
| Enter | 开始 / 重新开始 |

手机端打开会自动显示触屏方向键与发射按钮。

## 地图元素

- 🧱 砖墙：可被子弹摧毁
- 🪨 钢墙：不可摧毁（3 级火力除外）
- 💧 水域：坦克无法通过，子弹可以穿过
- 🌿 草丛：坦克可躲藏其中
- 🦅 基地：被敌军击中即失败

## 道具

| 图标 | 效果 |
| --- | --- |
| ⭐ | 火力 +1（提升射速 / 子弹数，3 级可击穿钢墙） |
| ❤️ | 生命 +1 |
| 🛡️ | 无敌护盾 10 秒 |
| 💣 | 轰炸：消灭场上所有敌军 |

## 在线游玩

启用 GitHub Pages 后可通过 `https://<你的用户名>.github.io/tank-battle/` 直接游玩。

## 本地运行

直接双击打开 `index.html`，或使用任意静态服务器，例如：

```bash
npx serve .
```
